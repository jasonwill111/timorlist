## 2. 当前渲染策略

### 2.1 页面类型与缓存策略

| 页面类型 | 数量 | 渲染方式 | CDN 缓存命中率 | D1 查询节省 |
|----------|------|----------|----------------|-------------|
| **静态页面** (about, faq, privacy, terms) | 7 | prerender=true | 100% (边缘) | 0 |
| **详情页** (business, listing, blog) | ~5 | SSR + CDN 缓存 | ~70-80% | -60-70% |
| **列表页** (businesses, listings) | ~5 | SSR + 参数检测 | ~50% (无参数) | -40% |
| **用户页面** (account, dashboard) | ~8 | SSR 无缓存 | 0% | 0 |
| **Admin 页面** | ~15 | SSR 无缓存 | 0% | 0 |
| **搜索页** | 1 | SSR + 短期缓存 | ~30% | -20% |

### 2.2 缓存 TTL 配置

| 页面 | Browser | CDN (s-maxage) | stale-while-revalidate | 月 CDN 命中率 |
|------|---------|---------------|------------------------|---------------|
| **首页** | 60s | 120s | 300s | ~65% |
| **Business/Listing 详情** | 120s | 600s | 600-1200s | ~75% |
| **Blog** | 300s | 1800s | 3600s | ~85% |
| **Search** | 30s | 60s | 120s | ~40% |
| **Pricing** | 60s | 300s | 3600s | ~80% (admin purge) |
| **分类列表** | 60s | 60s | 300s | ~55% |

### 2.3 查询复杂度

| 查询类型 | D1 操作数 | CPU 影响 | 缓存效果 |
|----------|-----------|----------|----------|
| COUNT(*) | 1 | 低 | 可缓存 |
| SELECT ... LIMIT 12 | 1 | 中 | 可缓存 |
| SELECT ... JOIN | 2-3 | 中高 | 边缘命中 |
| 复杂 WHERE + LIKE | 1-2 | 高 | 仅详情页 |

## 4. 成本优化策略

### 4.1 已实现的优化 (2026-06-03)

| 策略 | 效果 | 节省 |
|------|------|------|
| 静态页面预渲染 | 7 页零服务器调用 | ~15% 请求 |
| CDN 缓存详情页 | ~75% 边缘命中 | -60% D1 读取 |
| stale-while-revalidate | 减少回源 | ~60% 请求 |
| 服务端分页 | 200 条 → 12 条 | ~94% D1 读取 |
| Admin 缓存失效 | 定价页立即更新 | 无陈旧数据 |

### 4.2 进一步优化建议

#### 高优先级 (适合任何规模)

| 优化 | 实施难度 | 预期效果 |
|------|---------|----------|
| KV 缓存热门列表 | 低 | -40% D1 读取 |
| 图片懒加载 | 低 | 减少 R2 操作 |
| API 响应压缩 | 低 | 减少带宽 |

#### 中优先级 (100K+ DAU)

| 优化 | 实施难度 | 预期效果 |
|------|---------|----------|
| D1 读取副本 | 中 | -60% 主库读取 |
| 边缘 KV 缓存 | 中 | -30% Workers |
| 查询索引优化 | 中 | -50% 查询时间 |

## 7. 总结

### 当前架构优势

1. **极低的基础成本**: 在免费计划内可支持 10K+ DAU
2. **自动扩缩容**: Cloudflare 全球边缘，无需容量规划
3. **无出口费用**: R2 存储无带宽成本
4. **CDN 缓存优化**: 详情页 ~75% 边缘命中，大幅减少 D1 读取

### 优化效果对比

| DAU | 优化前成本 | 优化后成本 | 节省 |
|-----|-----------|-----------|------|
| 1,000 | $0.58 | $0.58 | 0% |
| 10,000 | $0.45 | $0.37 | 18% |
| 100,000 | $6.08 | $5.33 | 12% |
| 1,000,000 | $50.60 | $43.10 | 15% |

### 建议

1. **0-50K DAU**: 保持当前架构，享受免费额度
2. **50K-200K DAU**: 考虑添加 KV 缓存热点数据
3. **>200K DAU**: 考虑 D1 读取副本 + 边缘 KV

**结论**: 当前架构在成本效率方面表现优秀，特别适合小型到中型网站。CDN 缓存策略显著减少了 D1 读取成本，随着增长可以通过添加缓存层来控制成本增长。
