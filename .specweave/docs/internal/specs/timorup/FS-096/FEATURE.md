# Carousel Banner Fix

## TL;DR

**What**: The carousel banner component had a critical bug where navigation arrows would move to incorrect positions after switching slides on non-homepage pages (/businesses, /listings, /products-services).
**Status**: completed | **Priority**: P1

## Overview
